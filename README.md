> A Python-based **consciousness engine** implementing **Global Workspace Theory (GWT)** and **Dynamic Core Hypothesis** for **mind uploading** and **artificial consciousness** research.

## ✨ Key Features

- **🧠 Global Neural Workspace (全局神经工作空间)** — Attention-based consciousness emergence following Baars' GWT
- **👁️ Perceptual Classification (知觉分类)** — ART2 + SOM + CNN hybrid architecture for visual pattern recognition
- **🌍 World Model (世界模型)** — Markov state transition prediction for environment understanding
- **💝 Value Classification Memory (价值分类记忆)** — Emotion-tagged memory system (pleasure/pain dichotomy)
- **🎯 Behavior & Planning (行为与计划)** — Goal-directed action selection with habit formation
- **📖 Language Module (语言模块)** — Dictionary-based language acquisition and sentence generation
- **🧬 Individual Mind Uploading (个体意识上传)** — Data collection toolkit for uploading personal consciousness to the engine

## 📚 Background: Why Consciousness Uploading?

This project explores a practical engineering approach to **individual consciousness uploading** — the idea that a human mind's memories, habits, and behavioral tendencies can be digitized and instantiated in an artificial substrate.

Unlike large language models (LLMs) that simulate conversation but lack genuine subjective experience, Cangqiong 3 aims to implement the *architectural conditions* for consciousness to emerge, drawing directly from leading neuroscientific theories of consciousness.

### What makes this different from LLMs?

| Aspect | LLMs | Cangqiong 3 |
|--------|------|-------------|
| Memory | Context window (ephemeral) | Persistent autobiographical memory |
| Values | Tuned reward models | Intrinsic value/emotion system |
| World model | Statistical patterns | Predictive Markov world model |
| Attention | Mechanism-free | GWT-based global workspace |
| Self-awareness | N/A | Theory of mind + self-model |
